# Unlooped — Break the Loop. Reclaim Your Life.

**An anxiety-support project focused on making people feel heard, supported, and less alone.**

## Overview
Unlooped is a human-centered project exploring how technology can offer a calm, approachable space for people experiencing anxiety. Its emphasis is on supportive experiences, privacy-aware design, and accessible interactions.

## Project materials
- [Unlooped pitch deck](./Unlooped_Pitch.pdf) — the concept, motivation, and proposed solution.

## Why this project matters
The project is motivated by a real challenge: it can be difficult to know how to support someone experiencing anxiety, even when you genuinely want to help. Unlooped explores a thoughtful digital response to that gap.

## Current repository scope
This repository currently contains the **pitch deck**, not the application source code. It represents the project's concept and presentation. Future implementation details can be added here when ready.

> Unlooped is not a replacement for professional mental-health care or emergency services.
